# Patch 32
BLS now compares weighted box residual loss against a fitted intercept+sine+cosine at the selected BLS period. A singular sinusoidal fit or nonfinite loss rejects the candidate. This is a heuristic, not a calibrated false alarm probability; harmonics, mixed signals, real TESS and correlated-noise false positives remain unvalidated. Algorithm identifier changed to BLS-patch32-shape1; old manifests are not silently replayed with the new algorithm. Existing delta chi-square criterion retained. All 16 synthetic datasets now have assertions; see scripts/bls_patch32_test.log. JVM harness uses existing dependency stubs; full Android build not verified. Persistent photometry and comparison-star stability remain pending.

# Patch 31 — exploratory BLS validation
Extends the JVM test harness with three weak box transit injections (500, 1000, 2000 ppm) and three pure sinusoidal variability controls. See scripts/bls_patch31_test.log for actual outputs. Existing ten regression datasets passed. Weak injections were detected in this single seeded experiment; two of three sinusoidal controls triggered BLS. These exploratory cases are not a passing scientific validation suite. Weak tests use 1200 frequency steps, sinusoidal controls use the default grid with 1–4 day search. No production algorithm change. Persistent photometry history, comparison-star stability, model discrimination, Android build and real TESS validation remain open.
